# 生成过程中实时预览结果设计文档

## 背景

当前生成流程中，用户必须等待所有步骤完成到 100% 才能查看任何输出。实际业务中，文案类结果（商品画像、标题、关键词等）在生成过程中已经确定，用户希望尽早看到这些中间结果，减少等待焦虑。

## 目标

在不打断生成流程的前提下，允许用户在进度页实时查看已生成的文件，并在生成完成后自然过渡到完整结果页。

## 设计方向

**A 底部实时预览栏**

在进度动画下方增加一条横向可滚动的预览卡片栏，每个步骤完成后对应的文件卡片会依次出现。点击卡片可弹出轻量预览，不离开当前页面。

## 视觉设计

### 位置与结构

进度页垂直顺序：

1. 大字号百分比
2. 当前步骤文案
3. 流动进度条
4. **实时预览栏（新增）**
5. 底部步骤标签

### 预览栏

- 容器宽度 100%，最大宽度与进度条容器对齐
- `overflow-x: auto`，支持横向滚动
- 隐藏滚动条（WebKit `::-webkit-scrollbar` 和 Firefox `scrollbar-width`）
- 卡片间距 `0.75rem`
- 卡片进入时使用淡入 + 上移动画

### 预览卡片

- 固定宽度 `120px`，圆角 `var(--radius)`
- 背景 `var(--bg-secondary)`
- 边框根据状态变化：
  - 已完成：实线 `var(--border)`
  - 当前正在生成：虚线 `var(--accent)` + 脉冲动画
- 卡片内显示：
  - 文本文件：文件名 + 前 2 行内容摘要
  - 图片文件：缩略图（通过 `/api/result/{product_id}/{filename}` 加载）

### 预览浮层

- 复用现有的 `preview.js` 能力
- 点击文本卡片 → `window.previewText(url, name)`
- 点击图片卡片 → `window.previewImage(url, name)`

## 交互设计

### 生成过程中

- 每个 SSE 进度消息到达时，前端调用 `/api/result/{product_id}` 获取当前文件列表
- 与本地已缓存的文件列表对比，找出新增文件
- 新增文件对应的卡片以动画形式加入预览栏
- 若某步骤产生多个文件（如卖点同时生成 md 和 json），显示为一个「卖点」卡片，优先展示 md 内容

### 卡片状态

- **已完成**：边框实线，显示内容摘要，可点击预览
- **生成中**：边框虚线，显示「生成中...」，不可点击
- **未开始**：不显示卡片

### 完成过渡

- 进度到达 100% 时，预览栏已包含所有结果卡片
- 停顿 500ms
- 进度页淡出，结果页淡入
- 结果页复用 `/api/result` 数据渲染完整结果

### 错误处理

- 生成失败时，预览栏保留已成功生成的文件
- 当前进行中的卡片显示失败状态，用户仍可点击已完成的卡片查看

## 技术实现

### 需要修改的文件

- `src/coupangads/web/static/js/progress.js`：在进度更新逻辑中增加预览栏数据同步和卡片渲染
- `src/coupangads/web/static/css/components.css`：增加预览栏和卡片样式
- `src/coupangads/web/templates/index.html`：在 progress-state 中增加预览栏容器

### 数据接口

- 复用现有 SSE `/api/progress/{product_id}` 作为同步触发器
- 复用现有 `/api/result/{product_id}` 获取文件列表
- 复用 `/api/result/{product_id}/{filename}` 预览单个文件

### 同步策略

```
SSE message received
    → fetch /api/result/{product_id}
    → diff with cached file list
    → render new cards with fade-in animation
```

不启用定时轮询，避免额外请求。

## 验收标准

1. 进度页出现底部横向预览栏
2. 每完成一个步骤，预览栏自动出现对应卡片
3. 点击已完成卡片可预览文件内容
4. 生成完成后平滑过渡到结果页
5. 结果页仍显示完整结果
6. 生成失败时保留已生成文件的预览
