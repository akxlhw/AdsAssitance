# CoupangAds AI IP Logo 设计

## 背景

CoupangAds AI 是面向韩国 Coupang 电商平台的 AI 内容生成系统，目标用户为中国跨境卖家。品牌需要传达的核心气质是：**专业、冷静、可信赖的韩国买手/策略师**。

Logo 将用于：
- Web App 顶部 Header
- 左侧 Sidebar 小 Logo
- 画布工作台空状态水印
- 未来可能的 favicon、加载动画、品牌物料

## 设计决策

### 品牌性格

- **专业**：像一位熟悉韩国市场的资深买手，而不是炫技的 AI 工具。
- **冷静**：不喧哗、不卡通，视觉语言克制。
- **有主见**：用「洞察点」暗示系统能从实拍图中提取关键决策信息。

### 方案选择

经过视觉 companion 三轮对比，最终确定：

- **图标方案**：A. 洞察之 C
- **字标方案**：A. 衬线 + AI 黑标

## Logo 构成

### 图标

```svg
<svg viewBox="0 0 120 120" fill="none">
  <rect x="10" y="10" width="100" height="100" rx="28" fill="#111111"/>
  <path d="M84 38C84 38 56 30 40 48C24 66 36 88 56 88C72 88 82 76 84 72"
        stroke="white" stroke-width="10" stroke-linecap="round" fill="none"/>
  <circle cx="88" cy="60" r="8" fill="#FF5A5A"/>
</svg>
```

**元素解读：**

| 元素 | 含义 |
|------|------|
| 圆角方块底 | App 图标式稳定感，现代、易识别 |
| 未闭合的白色 C | CoupangAds 首字母，同时像放大镜/报告环，暗示分析与洞察 |
| 右侧珊瑚红点 | 买手在报告上圈出的「关键洞察」，点睛之笔 |

### 字标

- **主文字**：`CoupangAds`
  - 字体：Playfair Display（衬线体）
  - 字重：700
  - 气质：编辑感、高级感、冷静的专业形象
- **AI 标识**：小写 `AI` 置于黑色圆角标内
  - 字体：Space Mono（等宽体）
  - 处理：黑色背景 + 白色文字，与图标底色呼应
  - 位置：紧跟 `CoupangAds` 右上角，大小约为文字高度的 55%

## 配色

| 角色 | 色值 | 用途 |
|------|------|------|
| 墨黑 | `#111111` | 图标底、字标、AI 标背景 |
| 洞察红 | `#FF5A5A` | 仅用于图标右下红点，占比极小 |
| 米白 | `#FAFAF8` | 画布底色，与现有主题一致 |
| 纯白 | `#FFFFFF` | Header、Sidebar 背景 |

## 应用场景

### Header（完整版）

- 图标尺寸：34×34 px
- 字标：`CoupangAds` 22px + `AI` 小标
- 间距：图标与字标 12px

### Sidebar（紧凑版）

- 图标尺寸：28×28 px
- 字标：可隐藏 `AI` 标，仅保留 `CoupangAds` 17px，或仅显示图标

### 画布空状态水印

- 图标尺寸：130×130 px
- 透明度：10%
- 居中放置，作为品牌氛围元素

## 变体

| 变体 | 使用场景 |
|------|---------|
| 图标版 | favicon、加载动画、小尺寸容器 |
| 暗色版 | 深色模式、暗色背景物料 |
| 单色版 | 打印、水印、低对比度场景 |

## 禁忌

- 不要拉伸或改变 C 的弧度。
- 不要移动红点的位置（必须在 C 的开口处）。
- 不要使用除 `#FF5A5A` 以外的红点颜色。
- 不要把 `AI` 标放大到与主文字同高。

## 实现提示

1. 将图标 SVG 保存为 `src/coupangads/web/static/images/logo-icon.svg`。
2. 在 `index.html` 的 Header 和 Sidebar 替换现有文字 Logo 为 SVG + 字标组合。
3. 画布空状态可复用同一个 SVG，通过 CSS 控制尺寸和透明度。
4. 字标字体通过 Google Fonts 引入：`Playfair Display:700` 和 `Space Mono:700`。

## 验收标准

- [ ] Header 显示完整 Logo，比例协调。
- [ ] Sidebar 显示紧凑 Logo，不拥挤。
- [ ] 画布空状态水印可见但不抢眼。
- [ ] 暗色模式下图标可切换为白底黑字版本。
- [ ] Logo 在 16×16（favicon）到 180×180（水印）范围内保持清晰。
