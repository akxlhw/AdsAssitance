# 生成进度页设计文档

## 背景

当前 MVP 的生成进度页仅包含一个简单进度条、百分比和步骤 pill，视觉表现力不足，与产品主打的「韩系极简高级」定位不符。

## 目标

在不改变主题体系的前提下，重新设计生成进度页的视觉效果与动效，让等待过程显得沉静、高级、有品质感，同时清晰传达当前进行到哪一步。

## 设计方向

**A 沉静极简 · 流体进度**

以大面积留白、单一流动进度条、大字号百分比和精致的步骤标签为核心，营造韩系高级感。

## 视觉设计

### 布局

进度页居中展示，垂直排列三个核心元素：

1. **大字号百分比**（如 `42%`）
2. **当前步骤文案**（如 `正在生成商品标题...`）
3. **流动进度条**
4. **底部步骤标签行**（商品画像 / 标题 / 关键词 / 卖点 / INS / 图片）

移除现有的圆角步骤 pill，改用更克制的标签形式。

### 字体

- 百分比使用 `Playfair Display` 衬线字体，字号 `3rem`，字重 700
- 当前步骤文案使用 `Noto Sans KR`，字号 `0.9rem`，颜色 `var(--text-secondary)`
- 步骤标签使用 `Noto Sans KR`，字号 `0.75rem`

### 颜色

- 百分比：深黑 `var(--text-primary)`
- 当前步骤文案：灰色 `var(--text-secondary)`
- 进度条背景：`var(--bg-tertiary)`
- 进度条填充：渐变 `linear-gradient(90deg, var(--accent), var(--accent-secondary))`
- 已完成步骤标签：`var(--text-secondary)` + 小勾图标
- 当前步骤标签：`var(--accent)`
- 未完成步骤标签：`var(--text-secondary)` 50% 透明度

### 进度条

- 高度 `3px`，圆角 `2px`
- 最大宽度 `280px`，居中
- 填充部分带轻微发光阴影，增强流动感

## 动效设计

### 百分比数字

- 从旧值平滑过渡到新值，使用 `requestAnimationFrame` 或 CSS transition
- 持续时间约 `600ms`，缓动 `cubic-bezier(0.4, 0, 0.2, 1)`
- 避免直接跳变造成的廉价感

### 进度条

- 宽度变化使用 CSS transition，持续 `600ms`
- 填充层叠加一个从左到右的「流光」shimmer 动画，持续 `1.5s`，循环播放
- shimmer 使用半透明白色渐变条在进度条上层移动

### 当前步骤文案

- 步骤切换时，旧文案淡出（`opacity: 0`），新文案淡入
- 淡入淡出持续 `300ms`

### 步骤标签

- 已完成步骤出现小勾图标，颜色加深
- 当前步骤颜色变为 `var(--accent)`，带轻微发光
- 状态变化过渡 `300ms`

### 完成过渡

- 进度到达 `100%` 后停顿 `300ms`
- 进度页淡出（`opacity: 0`），结果页淡入（`opacity: 1`）
- 交叉淡入淡出持续 `400ms`
- 结果页顶部显示「生成完成」和文件数量摘要

## 交互

- 进度页不可跳过，不可取消
- 生成失败时保持当前进度，显示错误文案，进度条颜色可变为错误色

## 技术实现

### 需要修改的文件

- `src/coupangads/web/static/js/progress.js`：重写进度更新逻辑，增加数字动画、步骤标签状态管理
- `src/coupangads/web/static/css/components.css`：增加/调整进度页样式和动画关键帧
- `src/coupangads/web/templates/index.html`：调整 progress-state 结构（如需）

### 数据接口

复用现有 SSE `/api/progress/{product_id}`，无需后端改动。

## 验收标准

1. 进度页打开后显示大字号百分比、当前步骤文案、流动进度条、步骤标签
2. 百分比和进度条宽度随 SSE 消息平滑变化
3. 步骤切换时文案淡入淡出，标签状态正确更新
4. 进度到 100% 后平滑过渡到结果页
5. 保持韩系极简视觉风格，不使用过多颜色或复杂装饰
