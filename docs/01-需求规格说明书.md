# 需求规格说明书

> **CoupangAds — AI 电商内容生成系统**

---

## 1. 引言

### 1.1 目的

本文档定义 CoupangAds 系统的全部需求，作为产品设计、开发、测试和验收的依据。

### 1.2 范围

系统面向韩国 Coupang 电商平台，为宠物用品等视觉驱动型品类提供自动化内容生成服务，覆盖商品洞察、文案生成、视觉生成三大领域。

### 1.3 术语定义

| 术语 | 说明 |
|------|------|
| 商品画像 | 基于产品实拍图分析得出的结构化商品属性与定位描述 |
| 卖点区块 | 详情页中按模块组织的商品卖点，编号 B1-B9 |
| 详情页 | Coupang 商品详情页，由多张 2:3 竖屏图片组成 |
| A/B 风格 | A 风格=高级商业摄影风，B 风格=韩系生活方式场景风 |
| 断点续跑 | 长链路任务中断后，恢复执行时自动跳过已完成环节 |

---

## 2. 总体描述

### 2.1 产品愿景

成为面向韩国电商市场最高效的 AI 内容生产基础设施，让跨境卖家以最低成本获得本土级的内容质量。

### 2.2 用户画像

**核心用户：Coupang 跨境卖家**
- 团队规模：1~5 人
- 月 SKU：50~500
- 无专职韩文文案与设计师
- 核心痛点：语言障碍、内容产能不足、本土审美脱节

**次要用户：内容运营专员**
- 负责商品上架、详情页优化、社媒运营
- 诉求：批量生成后轻量审核即可使用

### 2.3 运行环境

- 客户端：Windows / macOS / Linux
- 网络：需访问云端 AI 模型服务
- 存储：本地文件系统（未来支持对象存储）

## 3. 功能需求

### 3.1 功能全景

```
输入层
  └── 产品实拍图文件夹

文本生成引擎
  ├── FR-001 商品画像分析
  ├── FR-002 商品标题生成
  ├── FR-003 关键词挖掘
  ├── FR-004 详情页卖点文案
  └── FR-005 社媒文案生成

图像生成引擎
  ├── FR-006 智能参考图筛选
  ├── FR-007 图片提示词组装
  └── FR-008 详情页图片生成

输出层
  └── 完整内容资产包
```

### 3.2 FR-001 商品画像分析

**描述**：基于产品实拍图，自动生成结构化商品识别报告。

**输入**：产品实拍图（3~10 张）

**输出**：商品画像报告（Markdown 格式）

**报告必须包含**：

| 章节 | 内容 |
|------|------|
| 基础产品信息 | 产品大类、具体名称、Coupang 韩文品类词、标品/半标品/非标品判断 |
| 产品事实提取 | 颜色、材质、尺寸、结构、图案、包装、配件、可见文字/LOGO |
| 核心需求池判断 | 主需求池、次需求池、不建议进入的需求池 |
| 需求结构表达链 | 人群/宠物对象、使用场景、具体需求、核心卖点、证据/参数、购买理由、退货风险 |
| 核心卖点提炼 | 5-8 个结构化卖点 |
| 韩国转化判断 | 目标用户画像、适用犬种/猫种、购买动机、价格定位、转化优势/风险 |
| 主图点击力判断 | 点击力评分（1-10）、优势、不足、建议补充图片 |
| 详情页承接力判断 | 首屏/中段/后段建议、降低退货风险的信息 |
| 标题与埋词种子词 | 核心品类词、细分类词、场景词、功能卖点词、材质/结构词、风格词 |
| 新品期词库建议 | 关键词方向、否词方向、适合自动广告测试的词 |
| 韩国本地化视觉建议 | 推荐视觉风格、背景、宠物模特、拍摄角度、文案语气 |
| 合规与不确定信息 | 不得使用的卖点、图片无法确认的信息、需要补充的信息 |

**关键约束**：
- 所有判断必须基于图片中可见信息，不得虚构
- 未确认的属性标注「图片未明确」
- 严禁无依据断言

### 3.3 FR-002 商品标题生成

**描述**：基于商品画像，生成适配 Coupang 平台的高点击率韩文标题。

**输入**：商品画像报告

**输出**：多版本韩文商品标题（3~5 个变体）

**约束**：
- 符合 Coupang 平台 SEO 规则
- 自然嵌入核心关键词，避免堆砌
- 适配韩文用户搜索习惯

### 3.4 FR-003 关键词挖掘

**描述**：构建三层关键词矩阵，并提供蓝海词推荐。

**输入**：商品画像报告 + 商品标题

**输出**：结构化关键词文档

**输出格式**：
- 核心词（品类词）
- 属性词（材质/功能/风格）
- 长尾词（场景/人群/痛点）
- 蓝海词推荐（搜索量适中、竞争度低）
- 不建议使用的词及原因

### 3.5 FR-004 详情页卖点文案

**描述**：按模块化结构生成详情页卖点文案。

**输入**：商品画像报告 + 商品标题 + 关键词

**输出**：
- `selling_points.md`：Markdown 格式原始文案
- `selling_points.json`：B1-B9 结构化数据

**格式要求**：
- B1~B9 共 9 个卖点区块
- 采用 FAB 法则（Feature-Advantage-Benefit）
- 每个区块包含：卖点标题、韩文正文、支撑证据

### 3.6 FR-005 社媒文案生成

**描述**：生成适配 Instagram 平台的种草文案。

**输入**：商品画像报告 + 商品标题 + 关键词 + 卖点文案

**输出**：Instagram 文案（含 Hashtag 组合）

**约束**：
- 视觉导向 + 简短文案
- 适配韩国 Instagram 用户阅读习惯
- Emoji 使用自然，不堆砌

### 3.7 FR-006 智能参考图筛选

**描述**：从全部产品实拍图中选出 3 张最适合作为 AI 生图参考的图像。

**输入**：全部产品实拍图

**输出**：3 张最佳参考图标识

**筛选标准**：
- 产品主体清晰、无遮挡
- 光线均匀、色彩还原准确
- 能最好地展示产品颜色、材质、图案、结构
- 自动排除疑似 AI 生成图

### 3.8 FR-007 图片提示词组装

**描述**：将卖点文案、风格规则、产品上下文组装为图片生成提示词。

**输入**：
- 风格规则（A/B 双风格）
- B1-B9 结构化卖点
- 精简产品上下文

**输出**：18 条图片生成提示词（A 风格 × 9 个卖点 + B 风格 × 9 个卖点）

### 3.9 FR-008 详情页图片生成

**描述**：基于提示词和参考图，批量生成详情页图片。

**输入**：
- 组装好的图片生成提示词
- 3 张精选参考图
- 图片生成全局约束

**输出**：18 张 PNG 图片（A_B1~A_B9 + B_B1~B_B9）

**图片规格硬约束**：

| 属性 | 要求 |
|------|------|
| 比例 | 2:3 竖屏 |
| 推荐尺寸 | 1200 × 1800 px |
| 风格 | 韩系高级宠物品牌广告、真实摄影感、温暖治愈 |
| 文字语言 | **必须韩文**，严禁中文、英文、乱码 |
| 产品还原 | 严格还原参考图的颜色、材质、图案、LOGO、结构、版型 |
| 宠物模特 | 小型犬优先马尔济斯/泰迪/博美/比熊；猫优先布偶/英短/银渐层 |
| 人物模特 | 仅在主人互动场景出现，不喧宾夺主 |
| 禁止项 | 价格促销、医疗化表达、多余动物、杂乱背景、卡通风、廉价感 |

**10 屏内容结构（宠物服饰类）**：
1. 主视觉氛围图
2. 实景穿搭展示
3. 主人互动场景
4. 核心卖点功能展示
5. 产品细节特写
6. 产品纯图展示：正面
7. 产品纯图展示：侧面
8. 产品纯图展示：背面
9. 适用场景展示
10. 尺码/适用对象/购买提醒展示

**10 屏内容结构（宠物玩具类）**：
1. 主视觉互动海报
2. 真实玩耍场景
3. 主人互动场景
4. 核心功能卖点展示
5. 产品细节特写
6. 产品纯图展示：正面
7. 产品纯图展示：侧面
8. 产品纯图展示：背面
9. 产品单品白底图
10. 尺寸对比展示

## 4. 非功能需求

### 4.1 性能

| 指标 | 目标 |
|------|------|
| 单产品文本链路耗时 | ≤ 5 分钟 |
| 单张图片生成耗时 | ≤ 60 秒 |
| 图片预处理耗时 | ≤ 3 秒/张 |
| 断点检测跳过速度 | ≤ 5 秒/产品 |

### 4.2 可靠性

| 场景 | 要求 |
|------|------|
| API 临时错误（429/500/502/503/504） | 自动重试，最多 3 次，间隔 2 秒 |
| 单张图片生成失败 | 记录错误，跳过继续处理下一张 |
| 单个产品处理失败 | 记录异常，继续处理下一个产品 |
| 图片文件读取失败 | 跳过该文件，继续处理其他图片 |
| 模型返回非结构化文本 | 多层 fallback：正则提取 → 文本兜底 → 本地组装 |

### 4.3 断点续跑

- 默认行为：已存在的输出文件自动跳过
- 支持强制覆盖模式
- 图片阶段支持从指定键名恢复（如从 A_B4 恢复）
- 上游文件变更时，下游依赖文件自动识别为需重新生成

### 4.4 可维护性

- 提示词模板外置，调整输出内容时无需修改代码
- 代码注释以中文为主
- 日志格式统一：`YYYY-MM-DD HH:MM:SS | LEVEL | message`

### 4.5 扩展性

- 支持新增模型线路（复用现有函数结构，新增 Client Adapter）
- 支持新增产品品类（复制模板并修改 10 屏结构）
- 支持新增语言市场（替换韩文要求为日文/英文）

## 5. 验收标准

### 5.1 冒烟测试

1. 上传测试产品图，运行完整链路
2. 验证所有输出文件正常生成
3. 验证韩文输出无中文/英文混入
4. 验证图片为 2:3 竖屏比例
5. 验证断点续跑功能正常

### 5.2 质量基线

| 指标 | 合格线 | 优秀线 |
|------|--------|--------|
| 商品识别准确率 | ≥ 85% | ≥ 95% |
| 韩文文案可用率 | ≥ 80% | ≥ 90% |
| 图片产品还原度 | ≥ 80% | ≥ 90% |
| 图片合规率 | 100% | 100% |
| 整体可用率 | ≥ 75% | ≥ 85% |
