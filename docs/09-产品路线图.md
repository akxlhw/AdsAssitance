## 2. v1.0（当前版本）—— 基础链路

**状态**：✅ 已发布  
**时间**：2025-06  
**目标**：验证核心链路可行性，支持单机命令行批量生产

**功能清单**：
- [x] 商品画像分析
- [x] Coupang 标题生成
- [x] Wing 搜索词生成
- [x] 详情页卖点（B1-B9）生成
- [x] Instagram 文案生成
- [x] 智能参考图筛选
- [x] A/B 双风格详情页图片批量生成
- [x] Google Gemini 线路
- [x] 字节 Doubao 线路
- [x] 断点续跑与增量生成
- [x] 模板外置（Markdown / DOCX）

**已知债务**：
- 无单元测试覆盖
- 无 Web 界面，纯命令行操作
- API Key 明文存储
- 单线程串行处理

## 3. v1.5（规划中）—— 质量增强

**状态**：🟡 规划中  
**时间**：2025-Q3  
**目标**：提升输出质量，降低人工审核负担

### 3.1 功能规划

| 优先级 | 功能 | 说明 |
|--------|------|------|
| P0 | 质量审核层 | 自动生成后加一层规则校验 + LLM 评分，低于阈值自动重试 |
| P0 | 广告法敏感词过滤 | 硬编码禁用词库 + 正则匹配，拦截后再输出 |
| P1 | 批量优化模式 | 支持一次上传 50+ 产品，自动排队、自动限流 |
| P1 | 模板版本管理 | 模板支持版本号，可回滚到历史版本 |
| P1 | 输出对比工具 | 同产品多次生成的结果并排对比，方便运营选择最佳版本 |
| P2 | 图片后处理 | 自动压缩、格式转换、添加统一水印边框 |
| P2 | 穿戴方向识别（完整版） | 将经典版的 orientation 识别移植到完整版 |

### 3.2 技术债务偿还

- [ ] 为核心解析函数补充单元测试（覆盖率 ≥ 90%）
- [ ] 引入 pytest + pytest-cov 到开发流程
- [ ] API Key 支持环境变量读取
- [ ] 运行时性能基准测试和优化

## 4. v2.0（规划中）—— 平台化

**状态**：🟠 远期规划  
**时间**：2025-Q4 ~ 2026-Q1  
**目标**：从单机工具演进为可服务的 Web 平台

### 4.1 功能规划

| 优先级 | 功能 | 说明 |
|--------|------|------|
| P0 | Web 上传界面 | 拖拽上传产品图，可视化查看任务进度 |
| P0 | 任务队列（Celery + Redis） | 异步处理，支持并发和多 worker |
| P0 | 用户系统 | 多租户支持，数据隔离 |
| P1 | 结果管理后台 | 浏览历史生成记录、下载、分享、重新生成 |
| P1 | 对象存储集成 | 图片和文档持久化到 S3/MinIO/OSS |
| P1 | Webhook 通知 | 任务完成/失败时通知用户系统 |
| P2 | 用量统计面板 | 按产品/按时间维度的 API 调用统计和成本估算 |
| P2 | 团队协作 | 成员权限管理、审核工作流 |

### 4.2 架构演进

```
v1.x: 单机 CLI
    ↓
v2.0: Web 服务 + 任务队列
    ├─ Frontend: React/Vue 管理后台
    ├─ Backend: FastAPI/Flask
    ├─ Queue: Celery + Redis
    ├─ Storage: S3/MinIO (对象存储)
    └─ DB: PostgreSQL (任务状态、用户信息)
```

## 5. v3.0（愿景）—— 智能体

**状态**：🔵 愿景  
**时间**：2026 年及以后  
**目标**：从「按固定流程生成」演进为「能理解运营意图并自主决策的智能助手」

### 5.1 功能愿景

| 功能 | 说明 |
|------|------|
| 自然语言运营 | 运营说「帮我把这批夏季产品的标题改得更年轻化」，AI 自主拆解并执行 |
| 竞品分析 Agent | 自动抓取竞品页面，分析其标题、关键词、卖点策略，输出差异化建议 |
| 数据反馈闭环 | 接入 Coupang 销售数据，自动分析哪些内容转化好，反哺模板优化 |
| 自优化模板 | 系统根据历史生成效果和用户反馈，自动迭代优化提示词模板 |
| 多市场自动适配 | 同一产品自动适配韩国 Coupang、日本乐天、美国 Amazon 等多市场 |
| 实时 A/B 测试 | 自动生成多版本标题/主图，接入平台 A/B 测试框架，自动选择最优方案 |
