## 2. 环境准备

### 2.1 系统要求

| 项目 | 最低配置 | 推荐配置 |
|------|---------|---------|
| OS | Windows 10 / macOS 12 / Ubuntu 20.04 | Windows 11 / macOS 14 / Ubuntu 22.04 |
| Python | 3.10 | 3.11 ~ 3.12 |
| RAM | 4 GB | 8 GB |
| 磁盘 | 10 GB 可用 | 50 GB SSD |
| 网络 | 可访问 Google / 字节服务器 | 稳定国际带宽 |

### 2.2 Python 环境

```bash
# 检查 Python 版本
python --version  # 要求 >= 3.10

# 创建虚拟环境
python -m venv venv

# 激活环境
# Windows:
venv\Scripts\activate
# macOS / Linux:
source venv/bin/activate
```

### 2.3 依赖安装

```bash
# Google 线路
pip install --upgrade google-genai Pillow pillow-heif

# Doubao 线路
pip install --upgrade "openai>=1.0" Pillow pillow-heif

# 双线路同时安装
pip install --upgrade google-genai "openai>=1.0" Pillow pillow-heif
```

### 2.4 网络配置

**Google Gemini API**：
- 端点：`https://generativelanguage.googleapis.com`
- 部分地区可能需要代理访问

**字节 Ark Platform**：
- 端点：`https://ark.cn-beijing.volces.com/api/v3`
- 国内访问通常无需代理

## 3. 配置管理

### 3.1 API 密钥配置

```bash
# 基础配置（明文文件）
echo "YOUR_GEMINI_API_KEY" > apikey.md
echo "YOUR_DOUBAO_API_KEY" > dbkey.md
```

**安全加固**：
```bash
# 1. 加入 .gitignore
echo "apikey.md" >> .gitignore
echo "dbkey.md" >> .gitignore

# 2. 设置文件权限（Linux/macOS）
chmod 600 apikey.md dbkey.md

# 3. 生产环境建议使用环境变量
export GEMINI_API_KEY="sk-xxx"
export DOUBAO_API_KEY="sk-xxx"
```

### 3.2 模板文件配置

模板文件应放在项目根目录或指定模板目录：

```
项目根目录/
├── 入口脚本
├── 提示词模板/              # 可选：自定义模板库
│   ├── 默认版/
│   │   ├── 商品画像模板.md
│   │   └── ...
│   └── 自定义版/
│       └── ...
├── 输入目录/
└── 输出目录/
```

### 3.3 输入输出目录配置

```bash
# 默认配置
--input-dir 输入目录
--output-dir 输出目录

# 自定义配置
python 完整版入口 --input-dir /data/products --output-dir /data/outputs
```

## 4. 部署步骤

### 4.1 首次部署（单机）

```bash
# 1. 进入项目目录
cd /opt/coupang-ads

# 2. 创建虚拟环境
python -m venv venv
source venv/bin/activate

# 3. 安装依赖
pip install --upgrade google-genai "openai>=1.0" Pillow pillow-heif

# 4. 配置 API Key
echo "YOUR_KEY" > apikey.md

# 5. 创建输入目录
mkdir -p 输入目录

# 6. 验证（dry run）
python 完整版入口 --dry-run

# 7. 首次运行
python 完整版入口 --limit-folder "测试产品"
```

### 4.2 定时任务部署（Cron）

```bash
# 编辑 crontab
crontab -e

# 每小时检查一次新上传的产品
0 * * * * cd /opt/coupang-ads && source venv/bin/activate && python 完整版入口 --input-dir 输入目录 --output-dir 输出目录 >> /var/log/coupang-ads/cron.log 2>&1
```

### 4.3 Docker 部署（可选）

```dockerfile
# Dockerfile
FROM python:3.11-slim

WORKDIR /app

RUN apt-get update && apt-get install -y --no-install-recommends \
    libheif-examples \
    && rm -rf /var/lib/apt/lists/*

COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

COPY . .

ENV PYTHONUNBUFFERED=1

CMD ["python", "完整版入口"]
```

```bash
# 构建
docker build -t coupang-ads:latest .

# 运行
docker run -v $(pwd)/输入目录:/app/输入目录 \
           -v $(pwd)/输出目录:/app/输出目录 \
           -e GEMINI_API_KEY=$GEMINI_API_KEY \
           coupang-ads:latest \
           python 完整版入口
```

## 5. 运维监控

### 5.1 日志监控

```bash
# 实时查看当前运行日志
tail -f "输出目录/{产品名}/run.log"

# 查看所有产品的错误日志
grep "ERROR" 输出目录/*/run.log

# 统计成功/失败数量
grep -r "Saved image:" 输出目录/ | wc -l
grep -r "Failed to generate" 输出目录/ | wc -l
```

### 5.2 磁盘空间监控

```bash
# 检查输出目录大小
du -sh 输出目录/

# 检查单产品输出大小
du -sh "输出目录/{产品名}/"

# 清理旧输出（谨慎操作）
find 输出目录/ -type d -mtime +30 -exec rm -rf {} \;
```

### 5.3 API 配额监控

| 模型 | 配额限制 | 监控方法 |
|------|---------|---------|
| Gemini 2.5 Flash | Google Cloud 配额 | Google Cloud Console |
| Gemini 2.5 Flash Image | 同上 | 同上 |
| Doubao-seed-2-0-lite | 字节 Ark 平台配额 | 火山引擎控制台 |
| Doubao-seedream-5-0 | 同上 | 同上 |

**建议**：为每个产品记录 API 调用次数，估算月度成本。

### 5.4 告警规则

| 场景 | 告警条件 | 建议操作 |
|------|---------|---------|
| 单产品处理失败 | run.log 中出现 ERROR | 检查 API Key 和网络 |
| 连续多个产品失败 | 1 小时内失败数 > 3 | 切换模型线路 |
| 磁盘空间不足 | 可用空间 < 5 GB | 清理旧输出或扩容 |
| API 限流 | 429 错误频繁 | 降低并发或增加间隔 |

## 6. 备份与恢复

### 6.1 备份策略

| 数据类型 | 备份频率 | 备份方式 |
|---------|---------|---------|
| 提示词模板 | 每次修改后 | Git 版本控制 |

```bash

rsync -av backup/2025-06-09/输出目录/ ./输出目录/

# 恢复模板
git checkout -- 提示词模板/
```

## 7. 故障排查

### 7.1 常见问题速查

| 现象 | 可能原因 | 解决方案 |
|------|---------|---------|
| `FileNotFoundError: apikey.md` | API Key 文件缺失 | 创建文件并写入 Key |
| `No supported image files found` | 图片格式不支持或目录为空 | 检查图片格式和路径 |
| API 429 错误 | 请求过快 | 增加 `--request-delay` 或换线路 |
| API 500/502 错误 | 模型服务端故障 | 等待后重试或换线路 |
| 卖点解析为空 | 模型输出格式异常 | 查看卖点原始内容，手动修正 |
| 图片颜色偏差 | 参考图颜色不准确 | 更换更准确的参考图 |
| 韩文语法错误 | LLM 局限性 | 人工校对 |

### 7.2 调试模式

```bash
# 仅扫描输入，不调用 API
python 完整版入口 --dry-run

# 仅处理单个产品，快速验证
python 完整版入口 --limit-folder "测试产品" --overwrite

# 仅生成文本，跳过图片
python 完整版入口 --max-images 0

# 从断点恢复
python 完整版入口 --start-from A_B4
```
